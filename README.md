# Angelo A. Ramos — The Working Index

A distinct editorial portfolio designed as an engineering field journal.

## What's inside

- Six selected project records with image previews; QuickPrint and Fixed Assets Management each have two illustrative UI views.
- **DepEd LMS source exhibit**: Click **Browse the LMS prototype** in the first project record. This opens `lms-explorer/index.html`, a navigable read-only exploration of the supplied PHP prototype using original image assets. The archive includes landing, About, sign-in, sign-up, and news-template views.
- **AWS Certified Cloud Practitioner**: Real Credly share-badge embed using badge ID `3e2825e8-99d5-482b-a0e8-26c758e57ba9`, plus an external verification link. The live embed requires an internet connection and third-party scripts to be permitted.
- **LinkedIn**: Angelo's profile linked from Contact and structured data.
- Experience, technical responsibilities, method, and contact sections.

## Run and deploy

Open `index.html` locally or upload **the entire contents** of this directory to GitHub Pages, Netlify, Vercel, or another static host. Keep `lms-explorer/` and `assets/` folders. No build step is required.

A companion `angelo-ramos-portfolio-updated.html` single-file edition has image assets and an embedded LMS explorer in a modal. The separate standalone `angelo-ramos-lms-explorer.html` provides a one-file version of just the source exhibit.

## Important source limitations

The supplied `LMS-main.zip` contains PHP presentation pages, static assets, and sign-in/sign-up forms, but **not** `login_handler.php`, a database, or course-management backend. The exhibit is therefore a **faithful browseable reconstruction from the uploaded front-end files**, not a live LMS instance or an official DepEd website. All data-entry forms are disabled to avoid accepting personal information for a nonfunctional demo. The other five project previews remain **illustrative UI studies**, not verified application screenshots.

## Main files

- `index.html`, `styles.css`, `script.js` — portfolio
- `assets/previews/` — project visuals (including the source-based LMS exhibit thumbnail)
- `lms-explorer/index.html` — static LMS walkthrough (5 navigable sections)
- `lms-explorer/assets/` — original project images from the supplied LMS archive

The Credly embed and optional Google Fonts need network access, but the portfolio and LMS walkthrough otherwise operate offline.
